# InnovateTech

Official website for InnovateTech — a technology company building intelligent autonomous systems, robotics, IoT platforms, and creative media.

## Stack
- Plain static site (HTML + CSS + vanilla JS)
- No build step
- Hosted on GitHub Pages

## Local development
```bash
python3 -m http.server 8000
# or
npx serve
```

Open http://localhost:8000

## Assets
All project photography, CAD, and schematics live in `assets/img/projects/`.

## Deployment
GitHub Pages is configured to serve from the root of the `main` branch.

## Notes
- Contact details will be added by the team.
- All project data lives in `assets/js/projects-data.js` (used by the gallery).
- The design is intentionally hand-crafted and self-contained.
